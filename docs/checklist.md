# Чек-лист ручной проверки

Пройдите по пунктам через Swagger UI (`http://localhost:8080/swagger-ui.html`) до написания автотестов.
Отмечайте найденное и переносите в `docs/bug-reports`.

- [ ] Все эндпоинты из Swagger соответствуют `docs/requirements.md`
- [ ] Создание счёта: валидные и невалидные данные, границы (`0`, `-0.01`, 2 и 3 знака после запятой)
- [ ] Получение счёта: существующий, несуществующий, `id` не число
- [ ] Пополнение и снятие: границы суммы, весь баланс, больше баланса
- [ ] Заморозка: операции на замороженном счёте, разморозка, повторная заморозка
- [ ] Перевод: все ветки из REQ-6, атомарность из REQ-7
- [ ] Ответ API совпадает с БД после каждой операции
- [ ] Формат ошибок единый во всех методах
