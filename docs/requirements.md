# Требования к сервису Bank API

Документ описывает ожидаемое поведение сервиса. Любое отклонение от него считается дефектом.
Если в требовании чего-то не хватает, это вопрос к аналитику, а не повод придумывать поведение самому.

## Общие правила

- Формат данных JSON, кодировка UTF-8. Базовый адрес: `http://localhost:8080`.
- Денежные суммы это числа не более чем с двумя знаками после запятой.
- Ошибки возвращаются в формате `{"code": "...", "message": "..."}`.
- Порядок проверок во всех операциях: **валидация запроса (400) → существование счёта (404) → состояние счёта (409)**.
- Данные в таблице `accounts` базы данных всегда совпадают с тем, что возвращает API.

## Коды ошибок

| HTTP | code | Когда |
|------|------|-------|
| 400 | `VALIDATION_ERROR` | Тело запроса не прошло проверку полей |
| 400 | `INVALID_REQUEST` | Тело запроса нечитаемо или id в пути не число |
| 400 | `SAME_ACCOUNT` | Перевод со счёта на него же |
| 404 | `ACCOUNT_NOT_FOUND` | Счёт не существует |
| 409 | `ACCOUNT_FROZEN` | Операция на замороженном счёте |
| 409 | `INSUFFICIENT_FUNDS` | На счёте не хватает денег |

## Требования

| ID | Метод и путь | Правило |
|----|--------------|---------|
| REQ-1 | `POST /api/accounts` | Создаёт счёт. Тело: `owner` (непустая строка), `balance` (≥ 0, не более 2 знаков после запятой). Ответ `201`: `id`, `owner`, `balance`, `frozen = false` |
| REQ-2 | `GET /api/accounts/{id}` | Возвращает счёт (`200`). Счёта нет: `404 ACCOUNT_NOT_FOUND`. `id` не число: `400 INVALID_REQUEST` |
| REQ-3 | `POST /api/accounts/{id}/deposit` | Тело: `amount` (> 0, не более 2 знаков). Увеличивает баланс на `amount`, ответ `200` с обновлённым счётом. Счёт заморожен: `409 ACCOUNT_FROZEN` |
| REQ-4 | `POST /api/accounts/{id}/withdraw` | Тело: `amount` (> 0, не более 2 знаков). Уменьшает баланс. Счёт заморожен: `409 ACCOUNT_FROZEN`. `amount` больше баланса: `409 INSUFFICIENT_FUNDS`. Снять сумму, равную всему балансу, **можно**, баланс станет `0` |
| REQ-5 | `POST /api/accounts/{id}/freeze`, `.../unfreeze` | Меняет признак `frozen`, ответ `200` с обновлённым счётом. Повторный вызов не ошибка |
| REQ-6 | `POST /api/transfers` | Тело: `fromId`, `toId`, `amount` (> 0, не более 2 знаков). Переводит деньги между счетами, ответ `200`: `{from: счёт, to: счёт}`. Проверки по порядку: `fromId` равен `toId` (`400 SAME_ACCOUNT`), оба счёта существуют (`404`), счёт-отправитель не заморожен, счёт-получатель не заморожен (`409 ACCOUNT_FROZEN`), на счёте-отправителе хватает денег (`409 INSUFFICIENT_FUNDS`) |
| REQ-7 | `POST /api/transfers` | Перевод атомарен: если операция отклонена, балансы обоих счетов не меняются |
| REQ-8 | Все методы | Формат ошибки `{code, message}`, коды из таблицы выше |
