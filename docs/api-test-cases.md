# Тест-кейсы API

Формат: каждый кейс реализуется одним Spock-тестом (или одной строкой таблицы `where:`).
ID кейса указывается в названии теста, например `"TC-API-010: пополнение увеличивает баланс"`.

**Приоритет:** H, M, L. **Статус:** ✅ автотест написан и проходит, ❌ тест нашёл дефект, ⬜ не реализован.

Схема ID: `TC-API-0NN`, где десятки обозначают группу: 00x создание, 01x пополнение, 02x снятие, 03x заморозка, 04x перевод, 05x прочее.
