## BUG-002: `POST /api/transfers` возвращает 200 вместо 400 SAME_ACCOUNT при переводе на тот же счёт, баланс счёта увеличивается

| Поле                | Значение                                                                         |
|---------------------|----------------------------------------------------------------------------------|
| Обнаружен при       | Ручная проверка по `docs/checklist.md` (пункт про переводы, ветка «тот же счёт») |
| Связанный тест-кейс | TC-API-044                                                                       |
| Компонент           | `POST /api/transfers`                                                            |
| Окружение           | Java 17.0.12, коммит `4c3fd323`, PostgreSQL 16 в Docker                          |
| Серьёзность         | Critical                                                                         |
| Приоритет           | High                                                                             |
| Статус              | Open                                                                             |

**Предусловия:** нет.

**Шаги воспроизведения:**
1. Создать счёт: `POST /api/accounts` `{"owner": "Alice", "balance": 150}`, запомнить `id` из ответа.
2. Выполнить `POST /api/transfers` `{"fromId": {id}, "toId": {id}, "amount": 100}`.
3. Проверить баланс в БД: `SELECT balance FROM accounts WHERE id = {id};`

**Фактический результат:** `200`, баланс в БД стал `250.00` (был `150.00`). В теле ответа один и тот же счёт (`id: 1`) возвращается с двумя разными балансами: `from.balance = 50`, `to.balance = 250`.

**Ожидаемый результат:** `400 SAME_ACCOUNT`, баланс остаётся `150.00` (REQ-6).

**Последствия:** клиент может переводом на собственный счёт увеличивать баланс без пополнения, то есть создавать деньги.

**Причина (по ответу и коду):** нет проверки `fromId == toId`. Кроме того, один счёт загружается дважды как два отдельных объекта: списание сохраняется для первого, зачисление для второго, и последняя запись затирает первую.

**Доказательство:**

    POST /api/transfers  200
    {"from": {"id": 1, "owner": "Alice", "balance": 50, "frozen": false},
     "to":   {"id": 1, "owner": "Alice", "balance": 250, "frozen": false}}

**Автотест:** не написан (запланирован под TC-API-044).
