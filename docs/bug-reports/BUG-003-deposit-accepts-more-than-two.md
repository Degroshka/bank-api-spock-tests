## BUG-003: `POST /api/accounts/{id}/deposit` возвращает 200 вместо 400 при сумме с более чем двумя знаками после запятой, баланс в ответе не совпадает с БД

| Поле                 | Значение                                                                                        |
|----------------------|-------------------------------------------------------------------------------------------------|
| Обнаружен при        | Ручная проверка по `docs/checklist.md` (пункт «Ответ API совпадает с БД после каждой операции») |
| Связанные тест-кейсы | TC-API-012, TC-API-015                                                                          |
| Компонент            | `POST /api/accounts/{id}/deposit`                                                               |
| Окружение            | Java 17.0.12, коммит `c1014036`, PostgreSQL 16 в Docker                                         |
| Серьёзность          | Minor                                                                                           |
| Приоритет            | Medium                                                                                          |
| Статус               | Open                                                                                            |

**Предусловия:** нет.

**Шаги воспроизведения:**
1. Создать счёт: `POST /api/accounts` `{"owner": "Alice", "balance": 100}`, запомнить `id`.
2. Выполнить `POST /api/accounts/{id}/deposit` `{"amount": 0.0005}`.
3. Проверить баланс в БД: `SELECT balance FROM accounts WHERE id = {id};`

**Фактический результат:** `200`, в теле ответа `balance = 100.0005`, в БД `100.00`. Сервис подтвердил операцию, которую не выполнил.

**Ожидаемый результат:** `400 VALIDATION_ERROR`, баланс остаётся `100.00` (REQ-3).

**Последствия:** клиент получает успешный ответ и неверный баланс, а база остаётся без изменений; ответ API и БД расходятся (REQ-9).

**Причина (по поведению):** проверка количества знаков после запятой для пополнения не срабатывает, округление выполняет только колонка `numeric(19,2)` при записи. <Допишите, как ведут себя снятие и перевод, по результатам п. 3>

**Доказательство:**
```
POST http://localhost:8080/api/accounts/1/deposit
Content-Type: application/json

{"amount": 0.0005}
```
Ответ:

```
HTTP 200
{"id": 1, "owner": "Alice", "balance": 100.0005, "frozen": false}
```
Запись в БД:

```sql
SELECT balance FROM accounts WHERE id = 1;
-- результат: 100.00
```

**Автотест:** не написан (запланирован под TC-API-012).
